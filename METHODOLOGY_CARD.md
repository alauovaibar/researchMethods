## 2. Тип исследования (Research Type)

* **Тип:** **Количественное экспериментальное исследование (Quantitative Empirical Benchmark Study).**
* **Обоснование выбора:**  
  Исследование ставит целью выявление строгих причинно-следственных связей (causal relationships) и решение задачи оптимизации (parameter optimization) между непрерывными/дискретными числовыми параметрами конфигурации информационного поиска ($top\text{-}k$, $chunk\_size$, взаимное расположение контекста) и объективно измеримыми метриками генерации ответов языковой модели.  
  Оценка качества генерации опирается на строгие математические и статистические метрики (доля неподтвержденных утверждений — Hallucination Rate, метрика верности контексту — Faithfulness по стандарту RAGAs, лексическое и семантическое перекрытие Token F1, задержка инференса Latency). Анализ результатов проводится с использованием методов статистического вывода (дисперсионный анализ ANOVA, post-hoc тест Тьюки Tukey HSD при уровне значимости $\alpha = 0.05$). Качественные методы не обеспечивают требуемой воспроизводимости и статистической мощности для многофакторного сравнительного анализа гиперпараметров.

## 3. Формулировка гипотез (Hypotheses Formulation)

*Формулировка построена на основе аналитического синтеза Task 1 и литературы (Guu et al., 2020; Lewis et al., 2020; Liu et al., 2024; Cuconasu et al., 2024; Es et al., 2024).*

### Основная гипотеза (RQ1 — Влияние глубины извлечения top-k):
* **Нулевая гипотеза ($H_0^{(1)}$):**  
  Математическое ожидание уровня галлюцинаций ($\mu$) сгенерированных ответов статистически не различается при варьировании глубины извлечения $k \in \{1, 3, 5, 10, 20\}$ при фиксированных генеративной модели, ретривере и размере текстового блока:
  $$\mu_{k=1} = \mu_{k=3} = \mu_{k=5} = \mu_{k=10} = \mu_{k=20} \quad (\alpha = 0.05)$$
* **Альтернативная гипотеза ($H_1^{(1)}$):**  
  Существует статистически значимое нелинейное (U-образное) различие в уровне галлюцинаций в зависимости от $top\text{-}k$: при недостаточном $k$ ($k=1$) уровень галлюцинаций повышен из-за нехватки доказательной базы (under-contextualization), достигает глобального минимума при умеренном значении ($k \in [3, 5]$), а при дальнейшем наращивании $k \ge 10$ уровень галлюцинаций статистически значимо возрастает из-за эффекта отвлекающего шума (distractor passages) и рассеивания внимания LLM.

### Дополнительная факторная гипотеза (RQ2 — Взаимодействие chunk size и top-k):
* **Нулевая гипотеза ($H_0^{(2)}$):**  
  Эффект взаимодействия между размером чанка ($chunk\_size \in \{128, 256, 512, 1024\}$) и глубиной $top\text{-}k$ на уровень галлюцинаций отсутствует ($Interaction(top\_k \times chunk\_size) = 0$).
* **Альтернативная гипотеза ($H_1^{(2)}$):**  
  Существует значимое статистическое взаимодействие между размером фрагмента и глубиной извлечения: при малых чанках ($128$) требуется большее $k$ для компенсации потери связности, тогда как при крупных чанках ($1024$) увеличение $k$ ускоренно насыщает контекстное окно шумом, приводя к опережающему росту галлюцинаций.

### Дополнительная позиционная гипотеза (RQ3 — Позиционный сдвиг «Lost in the Middle»):
* **Нулевая гипотеза ($H_0^{(3)}$):**  
  Уровень галлюцинаций инвариантен относительно позиции релевантного фрагмента внутри извлеченного контекстного окна.
* **Альтернативная гипотеза ($H_1^{(3)}$):**  
  Уровень галлюцинаций статистически значимо выше, когда целевой фрагмент расположен в середине извлеченного контекста, по сравнению с позиционированием в начале или в конце контекстного блока (эффект U-образной кривой внимания декодера).

## 5. Выбранные метрики и Baseline (Metrics & Baseline)

### Первичная метрика (Primary Metric):
* **Hallucination Rate ($HR$) / Faithfulness Score ($F$):**  
  Главный критерий проверки гипотезы $H_1$. Определяется как отношение количества неподтвержденных семантических предикатов/фактов в сгенерированном тексте к общему числу фактов в ответе:
  $$HR = \frac{|\text{Unsupported Claims}|}{|\text{Total Claims in Answer}|}, \quad F = 1.0 - HR$$
  Значение $HR = 0.0$ означает абсолютную фактическую обоснованность ответа внешним контекстом.

### Вторичные метрики качества (Secondary Quality Metrics):
* **Token F1:** согласованность с эталонным экспертным ответом.
* **Exact Match (EM):** строгое вхождение ключевого факта/сущности.
* **Context Recall:** факт попадания золотого документа в top-$k$ извлеченных пассажей.

### Пороговые метрики безопасности (Guardrail Metrics):
1. **$P95\ Latency \le 2500\text{ ms}$:** задержка ответа не должна превышать допустимый порог интерактивного диалога реального времени.
2. **$Max\ Context\ Window \le 8192\text{ tokens}$:** жесткий предел токенов контекста модели; комбинации, приводящие к превышению, отсекаются.
3. **$Pipeline\ Error\ Rate = 0.0\%$:** полное отсутствие исключений, таймаутов или HTTP/5xx сбоев.
4. **$RAM\ Consumption \le 4096\text{ MB}$:** процесс не должен превышать лимит доступной памяти контейнера.

### Контрольная группа / Бэйзлайн (Baseline):
* **Baseline 0 (Zero-shot / No-RAG, $k=0$):**  
  Генерация ответа моделью исключительно на основе внутренней параметрической памяти без извлечения внешних документов. Позволяет зафиксировать базовую склонность модели к спонтанным галлюцинациям.
* **Baseline 1 (Standard Vanilla RAG):**  
  Индустриальная эвристическая конфигурация по умолчанию:
  * $top\_k = 3$
  * $chunk\_size = 256$ токенов
  * Без пересортировки и фильтрации шума.  
  Все модификации параметров сравниваются относительно данного бэйзлайна для вычисления дельты эффекта ($\Delta HR$, $\Delta Latency$).
